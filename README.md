## About the Project

**Student Learning Portal** is an educational web project where students can access lessons, practice problems, and track their progress. It is built to make learning *easy*, **organized**, and ~~confusing~~ fun.

Git Repository: [https://github.com/Ujjal1612/student-learning-portal](https://github.com/Ujjal1612/student-learning-portal)
